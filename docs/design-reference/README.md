# Referência de Design — ReqQuest

Estas imagens foram geradas como base visual do projeto (identidade "RPG de
Consultoria de Requisitos", mascote Reqi) e usadas como referência durante a
construção do site. Elas **não são a especificação final** — várias decisões
mudaram ou foram adaptadas na hora de programar (ex: paletas por mundo, layout
de componentes), então trate como inspiração, não como pixel-perfect.

- `00-mascote-pose-original.png` — primeira arte do Reqi (pose comemorando).
- `01-prancha-de-estilo.png` — paleta de cores, tipografia, amostras de UI e
  mini paletas dos 6 mundos.
- `02-mockup-tela-de-jogo.png` — referência de layout da tela de jogo (mundo
  Estação Espacial).
- `03-icon-sheet-powerups-badges.png` — folha original com os 3 ícones de
  power-up e os 4 selos de conquista (já recortados individualmente em
  `../../assets/icons/`).
- `04-icon-sheet-menu-mundos-classificacao.png` — folha original com os 5
  ícones de menu, os 6 ícones de mundo e os 2 ícones de classificação (já
  recortados individualmente em `../../assets/icons/`).
- `05-mascote-3-poses.png` — folha original com as poses neutro/confuso/
  empolgado do Reqi (já recortadas em `../../assets/mascot/`).

Os arquivos já recortados e prontos para uso no código estão em `assets/icons/`
e `assets/mascot/` (pasta irmã de `docs/`).
